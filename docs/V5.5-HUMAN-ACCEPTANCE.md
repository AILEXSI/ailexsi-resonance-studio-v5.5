## Operator checklist

1. Build on Windows: `BUILD_AND_RUN_V5.5.cmd` or `npm run tauri:exe`.
2. Confirm Task Manager process **AILEXSI Resonance Studio V5.5**.
3. Confirm toolbar chip is exactly **`V5.5.0`** (top-right).
4. Open Export. Confirm **`Frame Engine: AILEXSI`**.
5. Export a 720p30 timeline to MP4. Confirm **Fertig** + `Exported … bytes`.
6. Confirm a failed/unreadable clip surfaces a typed **`AFE_*`** error — export must not silently paint HTMLVideo frames.
7. Confirm preview still plays HTMLVideo.
8. Confirm V5 AppData is untouched (`com.ailexsi.resonance-studio-v5`). V5.5 uses `com.ailexsi.resonance-studio-v5-5` and `resonance-studio-v5-5*` keys.
9. **1080p OPEN ISSUE** — do not mark 1080p HUMAN-PROVEN from this bootstrap.
