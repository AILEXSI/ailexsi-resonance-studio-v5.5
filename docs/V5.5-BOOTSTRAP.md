## What V5.5 is

V5.5 is V5 AFE-03 with Mediabunny **removed** and AILEXSI Frame Engine as the **only** export frame source.

Preserved from V5: Production Pass D–H (dynamic audio, stem import, track/chapter groups, volume automation, write volume), transport, VIS, mixer, save/export `.vN`, AFE-03 streaming/prefetch/plan optimizations.

No new product features. **1080p remains an OPEN ISSUE** (AFE-03 evidence is 720p30). The Export dialog still offers a 1080p size preset; that is not a 1080p acceptance claim.

## Identity / storage

- Toolbar chip is exactly **`V5.5.0`** (permanent top-right of the toolbar).
- Export dialog shows **`Frame Engine: AILEXSI`** from live `getFrameSourceBackend()`.
- localStorage / IndexedDB keys: `resonance-studio-v5-5*`.
- Tauri AppData folder is `com.ailexsi.resonance-studio-v5-5` (side-by-side with V5).

## Export

- Frame source: AILEXSI only.
